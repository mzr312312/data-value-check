# 采集点数据合并工具

## 简介

采集点数据合并工具是一款基于Python开发的桌面应用程序，旨在帮助用户快速处理和合并Excel文件中的采集点数据。工具支持多种数据处理选项，包括空白单元格处理、设备状态校验等，并能够将处理后的结果保存为新的Excel文件。

该工具适用于需要对大量采集点数据进行清洗、整理和分析的场景，例如工业自动化、物联网数据分析等领域。

---

## 功能特点

1. **文件选择与预览**：
   - 支持选择输入Excel文件。
   - 自动检测文件中的必要列（`采集点编码`、`采集点值`、`时间戳`）并显示前5行数据作为预览。

2. **输出设置**：
   - 用户可以自定义输出目录，程序默认使用当前工作目录。

3. **空白单元格处理**：
   - 提供多种空白单元格处理方式：
     - **保留空白**：不作任何处理。
     - **删除空白(左移值)**：删除空白单元格并将后续值左移。
     - **填充为0**：将空白单元格填充为数值`0`。
     - **填充为NULL**：将空白单元格填充为字符串`NULL`。

4. **设备状态校验**：
   - 根据采集点值的变化判断设备是否处于停机状态。
   - 如果启用状态校验，会在输出文件中新增一列`校验结果`，标记每个采集点的状态（如“开机”或“停机”）。

5. **进度条与日志记录**：
   - 提供进度条实时显示处理进度。
   - 记录详细的操作日志，方便用户跟踪处理过程。

6. **多线程处理**：
   - 数据处理在后台线程中运行，避免GUI界面冻结。

7. **结果保存**：
   - 处理后的数据会保存为一个新的Excel文件，文件名包含时间戳以便区分。

## 使用说明

### 安装依赖

在使用本工具之前，请确保已安装以下依赖库：

- `pandas`
- `numpy`
- `openpyxl`

可以通过以下命令安装依赖：

```bash
pip install pandas numpy openpyxl
```

### 启动程序

1. 将代码保存为一个Python文件（如`excel_merger.py`）。
2. 在终端中运行以下命令启动程序：

   ```bash
   python excel_merger.py
   ```

3. 程序启动后会弹出一个图形化界面。

### 操作步骤

1. **选择输入文件**：
   - 点击“选择Excel文件”按钮，选择需要处理的Excel文件。
   - 程序会自动检测文件内容并显示前5行数据作为预览。

2. **设置输出目录**（可选）：
   - 默认情况下，处理结果会保存到当前工作目录。
   - 如果需要更改输出目录，点击“选择输出目录”按钮并指定目标文件夹。

3. **配置处理选项**：
   - 在“处理选项”区域，选择空白单元格的处理方式。
   - 如果需要启用设备状态校验，将“启用状态校验”选项设置为“是”。

4. **开始处理**：
   - 点击“开始处理数据”按钮，程序会自动读取输入文件并按照配置的选项进行处理。
   - 处理过程中，进度条会实时更新，操作日志会显示在日志区域。

5. **查看结果**：
   - 处理完成后，程序会弹出提示框显示结果文件的保存路径。
   - 结果文件名为`在线状态校验_YYYYMMDD_HHMMSS.xlsx`，其中`YYYYMMDD_HHMMSS`为当前时间戳。

---

## 输入文件格式要求

为了确保程序能够正确处理数据，输入的Excel文件需满足以下格式要求：

1. 必须包含以下三列：
   - `采集点编码`：唯一标识每个采集点的编号。
   - `采集点值`：采集点的具体数值。
   - `时间戳`：采集数据的时间，支持多种日期时间格式。

2. 时间戳列的数据应尽量规范，避免无效或无法解析的值。

3. 如果存在重复的时间戳记录，程序会自动保留第一条记录并删除其余重复项。

---

## 输出文件结构

处理后的结果文件包含以下列：

1. **采集点编码**：原始采集点的编号。
2. **校验结果**（可选）：如果启用了设备状态校验，此列为设备状态（如“开机”或“停机”）。
3. **时间1, 时间2, ...**：按时间顺序排列的采集点值。

|------------|----------|-------|-------|-------|

| A002       | 停机     | 20    | 20    | NaN   |

## 注意事项

1. **文件大小限制**：
   - 由于程序需要读取整个Excel文件到内存中，建议处理的文件大小不要超过1GB。如果文件过大，可能会导致内存不足。

2. **时间戳格式**：
   - 时间戳列必须能够被`pandas.to_datetime`函数解析。如果时间戳格式不规范，程序会将其标记为无效并记录警告。

3. **重复记录处理**：
   - 程序会自动删除完全重复的记录以及重复时间戳的记录（保留第一条）。

4. **异常处理**：
   - 如果在处理过程中发生错误，程序会弹出错误提示框并记录详细的错误信息到日志区域。
