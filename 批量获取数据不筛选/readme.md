
功能说明：

本软件包是为了校验扬州基地的IoT数据（在线状态）和实际开机状态是否一致用的，包含两个脚本：
1）按时间戳获取对应采集点的IoT读值-不筛选直接保存.py
2）在线状态表格重排.py

使用说明：
1）按时间戳获取对应采集点的IoT读值-不筛选直接保存.py
脚本功能：
1.通过刘涛的IoT接口获取对应采集点的IoT读值，并保存到本地文件，这些IoT值不会被筛选，而是全量保存。
2.运行脚本后，会生成两个文件：采集数据结果.xlsx和缺失数据点.xlsx。
3.采集数据结果.xlsx里，有3列：采集点编码、时间戳、采集点IoT读值。
4.输入文件是个时间戳，可以在代码中自定义时间范围，我设置的是30min，代表前后各30min，总共1小时的数据。

2）在线状态表格重排.py
脚本功能：  
1.通过GUI界面，读取合并后的采集数据结果.xlsx文件，根据采集点编码和时间戳对数据进行排序（一个采集点，1小时的IoT数据按时间戳排序），并生成新的排序后的文件。
2.可以设置输出目录
3.读取的采集数据结果.xlsx文件里，一个采集点有1个小时的IoT数据，有60行（个别的丢失点的，少于60行）
4.此脚本会把同一个采集点的数据合并成一行，按时间先后从左到右排序，并且对这一行数据进行校验，如果全部相同，则显示“停机”，如果存在至少两个不相同的值，则显示“开机”
